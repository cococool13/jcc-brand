JCC components

  • Buttons: Primary = blue (default action). Outline = secondary. Accent orange = one "Learn More" per view, navy text. Ghost-light on dark/photo only.
  • Card: White, 1px hairline, 8px radius, soft shadow. Optional icon, chip, title, copy, text link. Never nest cards.
  • Hero: Full-bleed photo under navy scrim (or brand band), eyebrow, slab-serif headline, one orange CTA + ghost button.
  • Header / nav: Color logo left (64px tall) on white, nav links right in navy semibold; hover turns orange-dark.
  • Footer: Navy, white logo file, tagline + URL, REQUIRED disclosure verbatim.
  • Form fields: Label above input, 4px radius, blue focus ring, help text in gray-9, primary submit.
  • Table: Blue-deep header with white text, hairline rows, zebra paper, right-aligned tabular numbers.
  • Stat / figure: Big slab-serif number in brand blue over a 3px blue rule; label in gray-9. On dark: white number, orange rule.
  • Quote band: Band-deep gradient (blue to blue-ink), orange kicker, slab-serif quote in white.
  • Badge and chip: Chip = pill, tinted (orange-wash/#9A560C or blue-wash/blue-deep) for topics. Badge = 4px radius, solid for status.
