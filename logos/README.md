# JCC logos

Naming: `jcc.<variant>.<color>.<ext>`. **color** = for light backgrounds; **white** = for dark/photo backgrounds.

| Variant | Light bg | Dark bg | Aspect (w:h) |
|---|---|---|---|
| Full logo (bridge + wordmark) | `svg/jcc.logo.color.svg` | `svg/jcc.logo.white.svg` | 1.90 : 1 |
| Icon (bridge in hexagon) | `svg/jcc.icononly.color.svg` | `svg/jcc.icononly.white.svg` | 0.96 : 1 |
| Social mark (hexagon + "JCC") | `svg/jcc.socialicon.initials.color.svg` | `svg/jcc.socialicon.initials.white.svg` | 0.69 : 1 |

`png/` holds the same six as transparent 600-dpi PNGs, plus `jcc.logo.color.with-website.png` (logo + URL lockup) and `jcc.favicon.web.png` (navy hexagon favicon as served on jacobsandcoolidge.com).

`favicon/`: `favicon.svg`, `favicon.ico` (32), `favicon-32.png`, `apple-touch-icon-180.png` (white bg), `icon-512.png`.
```html
<link rel="icon" href="logos/favicon/favicon.svg" type="image/svg+xml">
<link rel="icon" href="logos/favicon/favicon-32.png" sizes="32x32">
<link rel="apple-touch-icon" href="logos/favicon/apple-touch-icon-180.png">
```
SVGs were converted from the original 2017 Illustrator EPS files (vector paths, text outlined). Usage rules: see BRAND.md §2.
